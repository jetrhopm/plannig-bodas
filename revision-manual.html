Cómo usar este checklist
  1. Configura la URL base y el ID real de la boda que probarás.
  2. Inicia sesión con el rol indicado. Usa “Abrir flujo” para llegar directamente o sigue la ruta escrita.
  3. Realiza los pasos y compara con el resultado esperado.
  4. Marca la casilla, selecciona el estado y anota navegador, dispositivo, datos utilizados, resultado y mensaje de error.
  5. Exporta un respaldo JSON al terminar. Los cambios también se guardan automáticamente en este navegador.

Este archivo es independiente: no modifica la base de datos salvo las operaciones que tú ejecutes al abrir el sistema. Los comentarios permanecen únicamente en el almacenamiento local de este navegador.
